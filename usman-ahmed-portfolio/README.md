# Usman Ahmed — Personal Portfolio

A responsive black-and-white personal portfolio built with Next.js.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Production

```bash
npm run build
npm start
```

## Notes

- Replace `example.com` in `app/layout.tsx` with the final domain.
- Replace/add project links in `components/Portfolio.tsx` as needed.
- The portfolio currently shows 50+ projects as a headline and uses the 18 project contributions documented in the supplied resume as the visible project list.
